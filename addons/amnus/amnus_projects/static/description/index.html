AMNUS Projects

Project lifecycle extension for the AMNUS Odoo Project Lifecycle Management Platform.

Features

  • Extends standard Odoo projects and tasks — no duplicate project, task, stage or state models.
  • Handover from an approved CRM implementation request to a real project.
  • AMNUS project metadata: request link, request type, actual go-live, AMNUS tags.
  • Contractual deliverables with a controlled submit / accept / reject / reset workflow.
  • Server-side sign-off identity and timestamps, mandatory rejection reason.
  • Accepted deliverables protected from modification and deletion.
  • Optional task-to-deliverable link with same-project validation.
  • AMNUS project security groups, company isolation and project visibility rules.
  • Audit events and chatter on handover and deliverable transitions.

Reused standard functionality

  • Project stages (project.project.stage) for the project lifecycle.
  • Task stages and task states.
  • Project health (last_update_status).
  • Planned start (date_start) and planned go-live (date).

Odoo 19 Community Edition only. No Enterprise dependencies.
