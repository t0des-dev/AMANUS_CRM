AMNUS Agile

Agile and Scrum planning for the AMNUS Odoo Project Lifecycle Management Platform.

Features

  • Product backlog with user stories, business value, acceptance criteria, priority and Fibonacci Story Points.
  • Epics grouping stories per project with derived completion progress.
  • Sprints with backlog, manual capacity, commitment baseline, live and frozen metrics.
  • Explicit sprint lifecycle: draft, planned, active, closed, cancelled; closed sprints cannot be reopened.
  • Append-only sprint membership history with commitment snapshot, outcome and carry-over destination.
  • Explicit carry-over wizard for unfinished stories with reason and audit trail.
  • Structured sprint review and retrospective, including improvement actions and owner.
  • Event-based burndown and closed-sprint velocity reporting (line and bar graphs).
  • Server-enforced story completion: in progress, acceptance criteria set, manager only.
  • One task per story; execution data stays in standard project.task.
  • AMNUS Agile security groups, company isolation and project visibility rules.
  • Audit events on story state changes, sprint lifecycle, backlog updates and carry-over.

Reused standard functionality

  • project.task for execution: stages, states, assignees, deadlines, activities.
  • project.project as planning container.
  • amnus.tag for story classification.
  • amnus.audit.log for the audit trail.

Odoo 19 Community Edition only. No Enterprise dependencies. No duplicate task or stage models.
