AMNUS Core

Shared infrastructure for the AMNUS Odoo Project Lifecycle Management Platform.

Provides

  • Reusable tags (amnus.tag).
  • Shared audit log (amnus.audit.log).
  • Foundational AMNUS configuration (res.config.settings).
  • AMNUS root menu and security groups.

Security Groups

  • AMNUS User
  • AMNUS Manager (implies AMNUS User)
  • AMNUS Administrator (implies AMNUS Manager)

Odoo 19 Community Edition only. No Enterprise dependencies.
